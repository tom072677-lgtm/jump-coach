# Jump-Coach — 제자리멀리뛰기 영상 분석 데모 (Phase 1)

## 2026-10-29 구간별 피드백 변경

- 종합·자세 점수와 최고 자세 순위를 제거했습니다.
- 도약은 하강 말기, 팔 전방 스윙·추진, 이륙 직전의 마지막 지지 후보로 나눕니다. 공중·신발 최초 접촉 후보까지 다섯 장의 사진과 관찰·확인할 동작을 제공합니다.
- 착지 사진은 접촉 이후 가장 깊게 앉은 프레임을 사용하지 않습니다. 양발 뒤꿈치·앞부분과 신발 영상 영역을 확인해 첫 접촉 후보를 찾습니다.
- 착지 사진의 붉은 수평선은 접촉점–추정 무게중심 간격, 푸른 선은 접촉점–골반 관절점 간격입니다. 엉덩이 표면을 직접 측정하는 것은 아닙니다.
- 접촉점이 진행방향으로 앞서면 간격이 양수입니다. 큰 간격만으로 좋은 자세·추가 기록·뒤로 넘어지지 않음을 보장하지 않습니다. 착지 후 움직임은 별도로 관찰합니다.
- 가려진 발이 있으면 전체 최초 접촉을 확정하지 않습니다. 보이는 신발의 영상 접촉 후보는 px 참고 간격으로 표시할 수 있으며, 길이·접촉 기준 미확인 시 m/cm는 보류합니다.
- 사진의 프레임과 시간은 자동으로 자른 분석영상 기준입니다. 접촉 후보 범위와 추정 한계를 함께 확인하세요.

아래의 과거 설명·계획 중 점수나 착지 후 자세 평가에 관한 내용은 위 변경으로 대체됩니다.

휴대폰으로 찍은 **측면 점프 영상**을 넣으면, 자세 추정 → 관절 각도·무게중심 → 이지/착지 자동 검출 → 도약 각도·속도·추정 거리 → 규칙 기반 코칭 피드백을 한 번에 뽑아 주는 개념검증 도구입니다.

> 연구실 면담에서 "이미 첫 조각을 만들었다"를 보여주기 위한 데모. 정확도의 최종 검증은 운동역학 연구실의 지면반력기·모션캡처로 진행할 예정.

## 무엇을 하나

| 단계 | 내용 |
|---|---|
| 자세 추정 | MediaPipe **PoseLandmarker (Tasks API)**, 33개 랜드마크. 2D 이미지 좌표 + 3D world 좌표(미터) 동시 사용 |
| 무게중심(CoM) | **Winter/Dempster 분절 관성 파라미터**로 분절 질량중심을 합산한 전신 CoM (단순 중심점이 아님) |
| 관절 각도 | 3D world 좌표로 무릎·고관절·발목·팔 각도 계산 (원근 왜곡에 강함) |
| 필터링 | **Butterworth 4–6 Hz 저역통과**(filtfilt, zero-lag) — 운동역학 표준 |
| 이벤트 검출 | 발 최저점의 지면선 기준 자동 이지/정점/착지 검출 |
| 도약 속도·각도 | **체공 구간 CoM 포물선 피팅**으로 산출(접점 노이즈에 강함). 곡률에서 역산한 중력가속도 g를 **자체 검증 지표**로 출력 |
| 코칭 | 근거 기반 규칙(도약 속도 우선 → 각도 → 반동 → 팔스윙 → 착지). 임계값 출처는 `리서치 — 운동역학·마커리스 근거.md` |

산출물: `*.annotated.mp4`(스켈레톤+국면+지표 오버레이), `*.plots.png`(각도·CoM 4분할), `*.summary.json`(전체 지표+피드백).

## 설치 & 실행

```bash
# 의존성 (이미 설치됨: mediapipe, opencv-python, numpy, scipy, matplotlib)
python -m pip install mediapipe opencv-python numpy scipy matplotlib

# 모델 파일은 models/pose_landmarker_heavy.task 에 위치 (이미 다운로드됨)

python analyze_jump.py samples/slj_00003.mp4 --out out/slj3
```

옵션:
- `--scale-px-per-m <값>` : 픽셀→미터 스케일 수동 지정(정확한 절대 거리용). 미지정 시 근사 자동 스케일 사용.
- `--cutoff <Hz>` : 저역통과 차단주파수(기본 6).

## 자체 검증 — 중력 체크 (핵심 신뢰 지표)

체공 중 CoM는 중력만 받으므로 높이 곡선은 `y = c + v·t − ½g·t²`. 포물선을 피팅해 역산한 g가 **9.8 m/s²에 가까우면** 스케일·이벤트 검출이 내부적으로 일관됨을 뜻합니다.

- 정상 클립(slj_00003): `flight_gravity_check_mps2 = 9.55` ✅ (오차 ~3%)
- 부적합 클립(달리기 멀리뛰기, 모래밭 착지): `= 0.23` ❌ → 동시에 "flight time outside typical" 경고. **도구가 스스로 신뢰 불가를 알림.**

## 한계 (정직하게)

- **단안(單眼) 2D**: 깊이 모호성. 절대 거리·속도는 **근사**(자동 스케일 cv를 함께 출력). 정밀값은 수동 캘리브레이션 또는 연구실 검증 필요.
- **카메라 가정**: 정지된 카메라, 깨끗한 측면 뷰, 한 명, **제자리(두 발) 점프**. 패닝/줌/달리기 도약/다중 인물에서 이벤트 검출이 흔들릴 수 있음(경고로 표시).
- **가려진 쪽 관절** 정확도 저하(문헌상 camera-side 대비 오차 2배). → 측면 뷰에서 카메라 쪽 다리가 잘 보이게 촬영.
- 코칭 임계값은 문헌 기반이나 **연구실 데이터로 재보정 예정**.

## 촬영 가이드 (최선의 결과)

1. **정지된** 휴대폰(삼각대), 점프 방향에 **수직**으로 측면 촬영.
2. 전신이 프레임 안에 들어오게, 점프 전후 1초 여유.
3. 가능하면 **고프레임(60·120fps)** — 짧은 이지 구간을 더 잘 잡음.
4. 배경에 **알려진 길이의 기준물**(예: 1 m 막대)을 두면 정확한 스케일 캘리브레이션 가능.
